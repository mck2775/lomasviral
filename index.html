Lomasviral

Lomasviral is a personal tool operated by its developer. It connects the developer's own TikTok account, with the developer's explicit authorization through TikTok Login Kit, to:

  • read the account's basic profile information and statistics (followers, likes, number of videos);
  • read the list of the account's public videos, to measure performance;
  • upload videos to the same account through the TikTok Content Posting API, initiated by the account owner.

The tool is not offered to the general public and does not collect data from other TikTok users through the TikTok API.
